Aqui va la clave del Admin SDK de Firebase (para enviar notificaciones push).

NO se sube a git (esta carpeta esta en .gitignore, salvo este LEEME).

Pasos:
  1. Firebase Console -> Configuracion del proyecto -> Cuentas de servicio
     -> Generar nueva clave privada -> se descarga un JSON.
  2. Renombra ese JSON a "firebase-admin.json" y dejalo en esta carpeta:
        backend/secrets/firebase-admin.json
  3. En tu .env (raiz) define la ruta que usa el backend dentro del contenedor:
        FIREBASE_CREDENTIALS_PATH=/app/secrets/firebase-admin.json
     (en docker-compose la carpeta se monta como /app/secrets)
  4. Reconstruye el backend: docker compose up -d --build backend

Si FIREBASE_CREDENTIALS_PATH queda vacio, el push se deshabilita y el resto de
la app sigue funcionando normal (las notificaciones in-app por socket.io no
dependen de esto).
